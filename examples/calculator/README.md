# Hesap Makinası (Calculator)

Next.js ile oluşturulmuş basit bir hesap makinası uygulaması.

## Özellikler

- Temel aritmetik işlemler (+, -, ×, ÷)
- Yüzde hesaplama
- İşaret değiştirme (+/-)
- Ondalık sayı desteği

## Başlangıç

Uygulamayı çalıştırmak için:

```bash
npm install
npm run dev
```

Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresini açın.
